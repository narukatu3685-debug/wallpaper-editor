# 画面フロー

## 画面はアプリ全体で1つ（単一ウィンドウ、変更なし）

`ui-spec.md` のレイアウト（左: 対象画像一覧／中央: プレビュー＋Before-After比較／右: 調整パネル（4グループ・スクロール可能、**ウィンドウの上端から下端までフルハイト**）／下: アクションバー）をそのままTkinterのウィンドウとして実装する。画面遷移（別ウィンドウへの切り替え）は基本的に発生しない。トリミングのみ、プレビュー上に一時的なオーバーレイ（ドラッグ可能な矩形）を出す。

**2026-08-30更新（2回目）**: アクションバー（一括適用・壁紙設定・出力設定）は、右側の調整パネルの下まで回り込まない。**対象画像一覧＋プレビューの列（左・中央）の下にのみ配置し、調整パネルはその右で上端から下端まで通し**にする（本人からの指摘を反映）。

## 起動時の処理フロー（変更なし）

1. `%APPDATA%\WallpaperEditor\last_settings.json` を読み込み（無ければ初期値）、各コントロールに反映する
2. 起動時に指定された対象フォルダ（既定 `C:\壁紙\backup\ver3`。GUIから変更可能）をスキャンし、対応拡張子のファイル一覧を左パネルに表示する
3. 1枚目を自動選択し、プレビューに表示する

## 調整操作のフロー（F-01, F-07, F-09, F-11〜F-16, F-21, F-23）

1. ユーザーがスライダー/ボタンを操作するたびに、`AdjustmentSettings` の該当フィールドを更新し、`apply_adjustments()` をプレビュー画像1枚に対して再実行して即座に再描画する
2. 処理が重くなりうる項目（トーンカーブのドラッグ中、ぼかし等）は、ドラッグ中は間引いて描画し、ドラッグ終了時に最終描画する（デバウンス）。具体的な間引き間隔は実装時に体感で調整する
3. 「Before/After比較」（F-19）ON時は、加工前（元画像そのまま）と加工後（現在の設定を適用した画像）を並べて描画し、スライダーで比較位置を切り替える

### トリミングのフロー（F-15）

1. 「トリミングを開始」でプレビュー上に矩形オーバーレイを表示する（初期値: 中央80%）
2. ドラッグで移動、角のハンドルでリサイズできる
3. 「確定」で、プレビューの表示上の矩形座標を元画像サイズに対する相対座標（0.0-1.0）に変換し `AdjustmentSettings.crop_rect` に保存、プレビューにも反映する
4. 「解除」で `crop_rect = None` に戻す

### 自動補正のフロー（F-18、4パターン）

1. 4つのボタンのいずれかを押すと、現在プレビュー中の画像（元画像、加工前の状態）を対象に `auto_correct.py` の該当関数を実行する
2. 戻り値（`AdjustmentSettings`の一部）を現在の設定にマージし、各スライダーの表示値を更新した上で `apply_adjustments()` を再実行してプレビューに反映する
3. ログ欄に「自動補正「①オートコントラスト」を適用しました」のように結果を表示する
4. 適用後もユーザーは通常どおりスライダーで微調整できる（自動補正は初期値決めの補助という位置づけ、ui-spec.md §4.5）

## 「一括適用」ボタン押下時のフロー（F-03, F-05, F-20, F-27, F-28）

1. 現在の調整値・リサイズ値・出力設定（形式・バッチリネーム・高画質化トグル）を確定する
2. 出力先フォルダ名を確認（既定値 `<source>_edited_<timestamp>` を提示、変更可）
3. `batch.process_folder()` を実行し、進捗バーを更新しながら処理する
4. 完了後、`成功N件 / 失敗M件、保存先: <output_dir>` を結果表示する
5. 現在の調整値・出力設定を `last_settings.json` に保存する

## 「壁紙に設定」ボタン押下時のフロー（F-06、変更なし）

1. 確認ダイアログを表示する（「<選択中のファイル名> を、現在の調整内容で壁紙に設定します」）
2. 確定操作をしたら、選択中の画像1枚だけに `apply_adjustments()` を適用して一時ファイルに保存
3. `wallpaper.set_desktop_wallpaper()` でそのファイルを壁紙に設定
4. 成功/失敗をメッセージ表示する

## 起動時の処理フロー（F-10分の追記）

3.5. `wallpaper_slideshow.is_slideshow_supported()` を確認し、非対応OSならスライドショー欄を無効化（グレーアウト＋「このWindowsのバージョンでは使用できません」表示）。対応OSなら `get_slideshow_status()` を呼び、ON中ならトグルボタンを ON 表示・間隔プルダウンをWindows側の実際の値に合わせる。OFF中なら `last_settings.json` の `slideshow_interval_minutes` をプルダウンの初期値にする

## 「スライドショー」トグル押下時のフロー（F-10、新規）

1. OFF→ON: 直近の「一括適用」（F-03）の出力先フォルダ（未実行の場合はボタンを無効化し「先に一括適用を実行してください」とヒント表示）と、プルダウンで選択中の間隔（分）を `wallpaper_slideshow.enable_slideshow(folder, interval_minutes)` に渡す。成功したらボタンをON表示（緑）に、失敗したら `SlideshowError` の内容をログ欄にエラー表示しボタンはOFFのまま
2. ON→OFF: `wallpaper_slideshow.disable_slideshow()` を呼び、成功したらボタンをOFF表示に戻す
3. ON中に間隔プルダウンを変更した場合は、`enable_slideshow()` を選択し直した間隔で再実行し、その場で切り替える
4. 選択した間隔は `last_settings.json` の `slideshow_interval_minutes` に保存する（アプリ終了時、または変更時）
