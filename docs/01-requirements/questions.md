# 質問シート

このファイルは、AI からユーザーへの確認・判断依頼を書き出すためのものです。
チャットで一問一答するのではなく、このファイルに質問をまとめて書き出し、
ユーザーが「回答」欄に記入する運用にします（詳細は `CLAUDE.md` 参照）。

- 既存の質問がある場合、新しいラウンドとして見出しを追加していく（過去の質問・回答は消さない）
- AI は「回答」欄を自分で埋めない／ステータスを勝手に「回答済み」にしない
- 選択肢は「その他（自由記述）」を必ず最後に入れる。選択肢どうしは空行で区切る（レンダラによっては詰まって表示されるため）
- 回答を反映する前に、他の質問の回答と矛盾していないか・曖昧でないかを確認する。疑わしければ新しいラウンドで確認する（過信の防止）

  - 8) **自動補正ボタン** — ワンクリックで明るさ・コントラストを画像ごとに自動調整する（スライダーの初期値決めの補助）
