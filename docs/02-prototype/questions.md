# 質問シート

このファイルは、AI からユーザーへの確認・判断依頼を書き出すためのものです。
チャットで一問一答するのではなく、このファイルに質問をまとめて書き出し、
ユーザーが「回答」欄に記入する運用にします（詳細は `CLAUDE.md` 参照）。

- 既存の質問がある場合、新しいラウンドとして見出しを追加していく（過去の質問・回答は消さない）
- AI は「回答」欄を自分で埋めない／ステータスを勝手に「回答済み」にしない
- 選択肢は「その他（自由記述）」を必ず最後に入れる。選択肢どうしは空行で区切る（レンダラによっては詰まって表示されるため）
- 回答を反映する前に、他の質問の回答と矛盾していないか・曖昧でないかを確認する。疑わしければ新しいラウンドで確認する（過信の防止）

### Q-02 機能の重複整理（複数選択可）
- ステータス: 回答済み（1,2,4,5,6。露出・デヘイズ・ハイライト/シャドウを削除し、シャープネス/明瞭度・彩度/Vibranceは両方維持。ノイズ除去（3）は削除されず維持）
- なぜ聞くか: 「いろいろかぶってそうだから整理して」という指摘を受けて、効果が重なりやすい組み合わせを洗い出しました。番号を選んでいただければ、その項目を`feature-list.md`から削除します
- 選択肢（削除してよいものの番号をすべて回答欄に書いてください。例: 「1, 3」。何も削除しなくてよければ8）:

  - 1) **露出（F-22）を削除する** — 「明るさ」とどちらも画像全体を明るく/暗くする効果で、見た目の違いを出しにくいため

  - 2) **デヘイズ（F-25）を削除する** — 実質「コントラストと彩度を同時に上げる」効果に近く、個別のスライダーを持つ意味が薄いため

  - 3) **ノイズ除去（F-26）を削除する** — 「全体ぼかし」とどちらも画像を滑らかにする方向の効果で、デモでも視覚的な違いを出せていないため。本格的なノイズ除去アルゴリズムは効果が異なるが、実装難度も高い

  - 4) **シャープネスと明瞭度（F-12）はこのまま両方残す** — 輪郭強調（シャープネス）と質感・階調のメリハリ（明瞭度）という違いがあり、写真編集アプリでも両方持つのが一般的なため（参考として提示。特に問題なければ「対応不要」の意味で選ばなくてOKです）

  - 5) **彩度とVibrance（F-11）はこのまま両方残す** — 肌色保護の有無という明確な違いがあり、定番の組み合わせのため（同上、選ばなくてOK）

  - 6) **ハイライト／シャドウを削除し、トーンカーブに一本化する** — トーンカーブがあれば理論上ハイライト/シャドウの調整も代替できるため（ただし個別スライダーの方が分かりやすいという考え方もある）
